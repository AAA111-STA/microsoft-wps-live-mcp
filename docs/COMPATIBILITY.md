本机曾遇到 WPS 以兼容 Office 身份注册运行对象，以及旧 WPS 文档代理持续拒绝调用的问题。新建/载入关闭文件时直接激活注册的自动化服务并核对真实厂商；已打开文件仍先连接原文档，不重建文件、不修改系统注册。持久 STA 内复用自身已建立的应用连接。

环境检查遇到未就绪的外部文档时返回 `discovery_warnings`，继续列出能读取的其他文档；不将这些外部文档纳入自动保存。PowerPoint 原生窗口标识不受支持时以原生窗口、厂商进程目录和活动状态交叉核对；同名窗口仍无法消歧时不报告可见性已确认。

WPS 演示复测前，软件自己的“云空间已满”浮层曾阻塞 COM；关闭该遮挡浮层后完成 6 阶段复测。测试未修改云同步、账号或审批设置。这类软件弹窗与 MCP 服务自己的界面不同：服务不创建额外“让智能体操作”页面，但不能保证 Office/WPS 或智能体客户端不显示它们自己的提示。软件忙碌时停止后续步骤，保留已确认的阶段记录供检查。

WPS 在含脚注和引用域的文档中直接构建公式曾失败。当前适配先在临时原生文档中构建公式，再以 `FormattedText` 转移可编辑原生公式；临时文档只用于本次操作，随后关闭。WPS 文档初始化和软件忙碌也有版本差异；代码对同一对象等待就绪，仅对明确“未执行就被拒绝”的 RPC 错误重试，不重放未知执行结果。

- Excel 的全部透视表、数据连接、验证、条件格式、结构化表和各种图表；PPT 的全部母版、布局、主题、动画、媒体等，尚未做完整功能矩阵实测。
- 自动版式诊断、完整脚注 XML 校验、窗口截图、实时 XML 导出和工具级撤销历史等专用能力仍有缺口，见 [完整核对清单](FEATURE_AUDIT.md)。
- 不支持将普通签名文字或内容哈希作为证书数字签名。
- 交互式对话框、未公开接口、某些特殊 COM 接口与事件回调，不能保证由通用 get/set/call 覆盖。
- 不承诺任意 Office/WPS 版本、所有智能体客户端、全新电脑安装或所有复杂文件都已验证。

## 保存的边界

自动保存管理明确连接的文档，软件忙碌时延后；部分失败、只读或外部磁盘变化时暂停，状态中返回原因。手动保存或其他程序写盘都可能改变连接时的磁盘基准，不能假定一定来自同一实时窗口；出现冲突时先比较，必要时另存新文件。

自动保存观察器在 MCP 正常运行期间有效，不能替代软件自身恢复机制或异地备份。测试中的“手动修改”由直接操作原生缓冲区模拟，没有把键盘输入界面验收说成已经完成。

## 复现入口

- `python -B -m unittest discover -s tests -v`：协议、文件边界、冲突、线程、超时、自动保存、副本及配置回归。
- `scripts/smoke_native.py`：原生应用与打开/关闭场景。
- `scripts/smoke_mcp.py`：真实 stdio、图表、流程图与原生渲染，可加 `--mode legacy`。
- `scripts/smoke_features.py`：审校组件、公式、自动保存与副本。
- `scripts/smoke_live.py`：6 类原生可见分阶段构建、阶段落盘、进度及最终副本；`--installed --mode auto` 验证安装后的当前协议，`--mode legacy` 验证兼容协商。

运行时的报告和文档在 `data/`，不打包上传。公开工具 schema 在 [tools.json](tools.json)。GitHub Actions 配置已提供，尚未在远程 GitHub 仓库运行。
